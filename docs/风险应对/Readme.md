每一个文档都是分为详情 对策制定两个可以点击的地方。

关于表格，基本上都要做成可交互的，有操作按钮，可以点。

从整体进行设计，从宏观到微观。

## 主要模块

1. 四流不一致系统
2. 研发费用加计扣除系统
3. 补贴全流程管理系统。

## Layout

上方：
主菜单，每个菜单可以点开，点开之后，下方出现子菜单。

左侧：
当前项的菜单，每个菜单可以点开，点开之后，下方出现子菜单。

内容区域：
主要是做一个表格+展开行的效果，参考https://element-plus.org/zh-CN/component/table.html#%E5%B1%95%E5%BC%80%E8%A1%8C

## 风格

有科技感、现代感。

## 后台

没有数据库后台，所有数据都放在本地，通过json文件进行存储。

## 内容

大致分为两类：
1. 可交互的表格
2. Markdown
